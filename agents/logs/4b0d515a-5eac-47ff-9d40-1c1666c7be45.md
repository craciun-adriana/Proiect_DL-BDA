I created `AGENTS.md`, a logging script, and a hooks config. I tested the user-message logging with a fake prompt, and it wrote the entry correctly. I haven't tested the agent-output logging, which only runs when a real turn ends.

- **`AGENTS.md`** tells agents that every session needs its own log file at `agents/logs/<session_id>.md`. The log must contain every user message verbatim and every agent output (text replies and tool calls). It also gives a manual fallback for runtimes that don't run hooks.
- **`agents/log_turn.py`** is the script that does the logging.
  - It appends your message to the session log when you submit it.
  - When a turn ends, it reads the session transcript and appends the agent's text and tool calls from that turn.
  - It swallows its own errors, so a logging failure never blocks a session.
- **`.claude/settings.json`** runs that script as a hook when you submit a prompt and when a turn ends. This means the agent doesn't have to remember to run it.
- **`agents/logs/.gitkeep`** keeps the empty log folder in git.

The hooks load when a session starts. Restart Claude Code, or open `/hooks` once, so this session picks them up. Log files will be committed unless you add `agents/logs/*.md` to `.gitignore`. I haven't committed anything.
